Netflora Online

Plant Species Detection with AI

Project developed by Embrapa for automated forest inventory using drones and artificial intelligence. The tool analyzes aerial orthophotos and automatically identifies the location of plant species of interest, such as Acai, Brazil Nut, Palms, and other Amazon rainforest species.

Open Streamlit demo Switch language

The Streamlit demo may take a few minutes to load and process the orthophoto.

Technical foundation

To enable this solution, Embrapa structured the project using Python and the YOLO (You Only Look Once) object detection model, widely used in computer vision for automatic element identification in images. The original proposal was developed for cloud execution via Google Colab/Notebook, allowing orthophoto processing with AI support without requiring robust local infrastructure.

From this base, the code was adapted for local execution, expanding flexibility and enabling greater data control. Additionally, this public-access page was implemented, where anyone can upload an orthophoto and receive the analysis results in a practical and accessible way.

After processing, the page provides the generated files for export, especially the Shapefile format widely used in geographic information systems (GIS). This allows results to be integrated into topographic analysis, mapping and territorial planning tools, facilitating the technical use of the information obtained.

How does it work?

From raw imagery to the final map, the workflow runs in four focused stages.

01

Orthophoto

Georeferenced aerial image (.tif) captured by drone.

02

Tiles

The image is split into crops to facilitate model analysis.

03

Detection

A deep learning model identifies species in each crop.

04

Result

Detections are georeferenced and displayed on an interactive map.

Run locally

Local Python workflow (validated commands), adapted from the original Google Colab-oriented project to local execution. 

prepare python environment
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt

enter the adapted local workflow folder
cd workdir\netflora_src

generate tiles (cropped images for easier analysis)
python -c "from tiles import TileGenerator; TileGenerator()"

detect plants on tiles
python detect.py --device 0 --weights model_weights.pt --img 1536

detection confidence threshold workflow
python -c "from utils.batch_detection import runBatchDetection; runBatchDetection(device='cpu', img_size=1536, source_path='processing/selected_images', weights_path='model_weights.pt', save_txt=True)"
python -c "from utils.thresh_display import ImageDisplayer; ImageDisplayer()"

process results
python results.py --graphics --conf 0.25

show summary image (terminal may not render; output file is saved in results)
python -c "from results import showResults; showResults()"

create map and save as HTML
python -c "from utils.map_utils import createMap; m=createMap(); m.save('results/mapa.html')"

open map in browser (Windows)
start results\mapa.html

generate results zip
python -c "from results import downloadResults; downloadResults()"
