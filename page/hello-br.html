Netflora Online

Deteccao de Especies Vegetais com IA

Projeto desenvolvido pela Embrapa para o inventario florestal automatizado com uso de drones e inteligencia artificial. A ferramenta analisa ortofotos aereas e identifica automaticamente a localizacao de especies vegetais de interesse, como Acai, Castanheira, Palmeiras e outras especies da floresta amazonica.

Base tecnica do projeto

Para viabilizar esta solucao, a Embrapa estruturou o projeto com base em Python e no modelo de deteccao de objetos YOLO (You Only Look Once), amplamente utilizado em visao computacional para identificacao automatica de elementos em imagens. A proposta original foi desenvolvida para execucao em ambiente de nuvem, por meio do Google Colab/Notebook, permitindo o processamento de ortofotos aereas com apoio de inteligencia artificial sem exigir infraestrutura local robusta.

A partir dessa base, o codigo foi adaptado para execucao local, ampliando a flexibilidade de uso e possibilitando maior controle sobre os dados. Alem disso, foi implementada esta pagina de acesso publico, onde qualquer pessoa pode enviar uma ortofoto e receber o resultado da analise de forma pratica e acessivel.

Apos o processamento, a pagina disponibiliza os arquivos gerados para exportacao, incluindo especialmente o Shapefile, formato amplamente utilizado em sistemas de informacao geografica (GIS). Isso permite que os resultados sejam integrados a ferramentas de analise topografica, mapeamento e planejamento territorial, facilitando o aproveitamento tecnico das informacoes obtidas.

Como funciona?

Da imagem bruta ao mapa final, o processo ocorre em quatro etapas objetivas.

01

Ortofoto

Imagem aerea georreferenciada (.tif) capturada por drone.

02

Tiles

A imagem e dividida em recortes para facilitar a analise pelo modelo.

03

Deteccao

Um modelo de deep learning identifica as especies em cada recorte.

04

Resultado

As deteccoes sao georreferenciadas e exibidas em um mapa interativo.

Executar localmente

Fluxo local em Python (comandos validados), baseado na adaptacao do projeto original para execucao fora do Google Colab. 

preparar ambiente python
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt

entrar na pasta do fluxo local adaptado
cd workdir\netflora_src

gerar o tiles, imagens cortadas para facilitar a analise
python -c "from tiles import TileGenerator; TileGenerator()"

detectar plantas nos tiles
python detect.py --device 0 --weights model_weights.pt --img 1536

threshold de confianca de deteccao
python -c "from utils.batch_detection import runBatchDetection; runBatchDetection(device='cpu', img_size=1536, source_path='processing/selected_images', weights_path='model_weights.pt', save_txt=True)"
python -c "from utils.thresh_display import ImageDisplayer; ImageDisplayer()"

processar resultados
python results.py --graphics --conf 0.25

exibir imagem de resumo (no terminal pode nao renderizar; o arquivo fica salvo em results)
python -c "from results import showResults; showResults()"

criar mapa e salvar em HTML
python -c "from utils.map_utils import createMap; m=createMap(); m.save('results/mapa.html')"

abrir o mapa no navegador (Windows)
start results\mapa.html

gerar zip dos resultados
python -c "from results import downloadResults; downloadResults()"
